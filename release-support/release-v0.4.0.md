# 诗笺 0.4.0

东方美学桌面日历，Windows x64 Release 构建。

- 离线诗词由 8 首扩充至 2,008 首：从 chinese-poetry/chinese-poetry 固定提交筛选导入 2,000 首，保留原有 ID 和收藏。
- 当季与通用诗词混合推荐，避开近 30 天及最近 30 次选诗重复；当日主诗保持稳定。
- 五套主题、三套固定尺寸布局；允许拖动位置，禁止缩放，顶部按钮自动显隐。
- 灵签背景、文字、边框和按钮随当前皮肤同步。
- 支持国内城市搜索及天气缓存，收藏、每日诗词与签文保存在本机。

## 下载

- `诗笺_0.4.0_x64-setup.exe`：中文安装版。
- `诗笺_0.4.0_x64-portable.zip`：解压运行，记录仍保存在系统应用数据目录。
- `SHA256SUMS.txt`：安装包及便携包校验值。

Windows 10/11 x64，需要 WebView2；缺少兼容运行时时安装器需联网补齐。安装包尚未代码签名。天气使用 Open-Meteo 免费接口，限非商业用途；商业发布需更换符合用途的服务方案。

新增诗词提供原文来源，不编造译文或赏析；已做格式、繁简转换、去重和字体覆盖检查，尚未逐首人工校勘。上游来源清单与 MIT 许可随源码和安装包保存。灵签为传统文化娱乐体验。

验证：27 项业务测试、13 项浏览器检查通过，Windows Release 编译和 NSIS 打包通过。GitHub 本次发布为源码及构建产物发布，完整 V1.1 全量功能尚未全部实现。
