# 诗笺 0.4.2

仅诗词正文保留行书，其余文字统一改为楷体。

- 主界面诗句、诗词全文、收藏和历史中的诗句使用内置志莽行书。
- 时钟、日期、节气、时辰、诗名作者、按钮、设置、天气及灵签全部使用楷体。
- 辅助信息保留较粗字重，三套固定尺寸布局、五套皮肤、2,008 首诗词和 60 条灵签继续可用。

Windows 优先使用系统 KaiTi 楷体；系统未安装时使用可用的楷体或衬线字体回退。字体文件不从系统复制分发。升级保留已有收藏和每日签文。
