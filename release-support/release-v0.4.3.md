# 诗笺 0.4.3

诗名、朝代与作者合并为同一条竖列，三套模板统一生效，继续使用楷体。

- 移除诗名与作者之间的强制换列。
- 横版调整署名字号，常见诗名与作者可完整显示。
- 超长诗名在原列省略，保留作者；悬停可查看完整署名，点击诗句可查看全文。

## 下载

- `Shijian-0.4.3-windows-x64-setup.exe`：中文安装版。
- `Shijian-0.4.3-windows-x64-portable.zip`：便携版。
- `SHA256SUMS.txt`：校验文件。

Windows 10/11 x64，依赖 WebView2，安装包尚未代码签名。升级保留收藏和每日签文。

验证：2 项字体与布局浏览器检查通过，最长诗名在三套模板中均保持单列，作者完整显示且未与底部按钮重叠。
