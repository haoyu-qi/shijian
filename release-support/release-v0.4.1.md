# 诗笺 0.4.1

灵签库由 6 条扩充至 **60 条**，新增 54 条项目编写的生活签，涵盖从容、行动、相处、求知、自省和调养。

- 每条包含签句、签意和今日寄语，随当前皮肤展示。
- 保留原有六个签号、原文与历史记录；当天已抽结果保持不变。
- 待抽签页和设置页显示 60 条实际库容量。
- 诗词库保持 2,008 首，支持原有三套布局与五套主题。

## 下载

- `Shijian-0.4.1-windows-x64-setup.exe`：中文安装版。
- `Shijian-0.4.1-windows-x64-portable.zip`：解压运行。
- `SHA256SUMS.txt`：安装包及便携包校验值。

Windows 10/11 x64，需要 WebView2。安装包尚未代码签名。便携版用户记录仍保存在系统应用数据目录。灵签仅用于文化娱乐与生活寄语；新增签文为项目编写，不冒充古籍或庙签。

天气使用 Open-Meteo 免费接口，限非商业用途；商业发布需更换符合用途的服务方案。

验证：31 项业务测试、13 项浏览器检查通过（包含逐条检查全部 60 签），真实天气联网测试按默认配置跳过；Windows Release 编译及 NSIS 打包通过。
