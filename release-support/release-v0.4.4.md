# 诗笺 0.4.4

补齐全文阅读入口，原文与解读均在应用内离线阅读。

- 点击诗句、诗名或新增的「阅读全文」，均打开本地完整原文。
- 收藏和历史中的诗词可打开各自的全文，收藏操作作用于当前阅读的作品。
- 每次打开阅读页回到顶部，避免沿用设置、历史弹窗的滚动位置；长诗可滚动阅读，标题和关闭按钮保持可用。
- 阅读页采用「原文 / 解读」切换，不再跳转浏览器，无需登录或配置 API。
- 内置 436 首本地解读：19 首含白话释义、词语注释与赏析，另有 417 首标明 AI 整理的参考赏析；尚未覆盖的 1,572 首明确提示详解待补充，完整原文仍可离线阅读。
- 参考赏析按作者和完整原文严格匹配，保留来源与 MIT 许可。已有收藏、历史和每日结果不变。
- 保持诗词行书、其他文字楷体以及单列诗名作者。
