# 诗笺 0.3.2 · 灵签随肤

日期：2026-11-01。

灵签卡片使用当前生效皮肤的同一张 ImageGen 背景、纸色、墨色、辅助色、边框与印章配色，适用于手动、每日随机及自动选肤。此前统一的米黄写实卷轴不再用于签卡显示。

| 皮肤 | 灵签效果 |
| --- | --- |
| 宣纸雅韵 | 米黄宣纸、淡竹山水、墨字朱印 |
| 桃花春雨 | 浅粉纸面、桃花、深棕字与玫红印章 |
| 烟雨江南 | 青绿纸面、江南水墨、深青字 |
| 玄青月色 | 深蓝月夜、浅金文字、暖金印章与按钮 |
| 雪落长安 | 霜白纸面、梅枝雪山、青灰文字与朱红印章 |

抽签入口采用可随主题着色的 SVG 线描签筒，避免写实棕木器物与皮肤脱节。签文仍为内置行书原生文字；已有每日签文、历史和收藏不重新生成或清空。

背景素材复用 `public/themes/{paper,blossom,rain,moon,snow}-v1.png`，未新生成或修改图片；原生主题配置控制前景。原始生图提示词见 `docs/imagegen-prompts.md`。

继续保持模板固定大小、允许拖动位置、按钮移入显示/移出隐藏、国内城市搜索。安装包为未代码签名的 Windows x64 Release 构建，需要 WebView2。
