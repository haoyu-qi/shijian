# 诗词库扩充记录

日期：2026-11-01；应用版本：0.4.0。

## 来源与数量

来源为 [chinese-poetry/chinese-poetry](https://github.com/chinese-poetry/chinese-poetry)，固定提交 `b8594f81a89752241442f2ce267d6f66f96704ee`，MIT 许可，Copyright (c) 2016 JackeyGao。

读取《唐诗三百首》《千家诗》及全唐诗分卷，共 61 个来源文件（含 LICENSE），解析 58,192 条原始作品记录。经格式、字形、长度和重复检查后有 25,208 条候选；优先纳入适合布局的选集作品，再按作者轮询补足 **2,000 首**。保留原有 **8 首**及其 ID，最终 **2,008 首**，共涉及 1,681 个作者名。

这是程序筛选与整理，不代表逐首完成历史版本和文本人工校勘。没有导入整个数十万条上游仓库，也没有把原文改写成 AI 诗句。

## 整理规则

- OpenCC 将繁体正文、标题和作者转换为简体；保留上游段落与原文信息。
- 去掉含替代字符、异常注释、超长标题、超长正文以及不适合竖排的记录。
- 每首展示的两句取自原文同一段，严格匹配同为五言或同为七言，不拼接无关句子。
- 使用实际内置的志莽行书字体检查全部汉字；不能覆盖的作品不入本版库。
- 按规范化作者/标题及全文去重，避免选集与全唐诗分卷重复。
- 原有 8 首保留旧 ID 和原有读诗小记。原文与解读分库管理；0.4.4 增加 436 首离线解读，不修改原文库。其中 19 首有释义与注释，另有 417 首带 AI 整理标记的参考赏析；其余篇目提示待补充。阅读不连接外部网站，详见 `docs/poem-readings.md`。
- 新作品使用上游 ID（无 ID 时使用内容哈希）构造稳定 ID，并保存来源文件和来源 ID。

## 推荐与记录

每日首次选择在当季与通用池中加权抽取，当季权重为通用作品的 3 倍；排除近 30 天每日记录以及最近 30 次选择。手动换诗从全库选取，排除当前作品和近期选择。候选不足时才扩大范围。

同一天已经展示的作品保持稳定；旧收藏、旧每日诗词和灵签记录不清空。首次升级可点击“换一首”立即查看新库。设置页显示诗词总数。

## 文件与复现

- `src/data/poems.curated.json`：旧版 8 首。
- `src/data/poems.imported.json`：新增 2,000 首。
- `src/data/poems.provenance.json`：固定提交、来源路径、SHA-256、数量和筛选统计。
- `public/licenses/chinese-poetry-MIT.txt`：随安装器与便携包分发的上游许可。
- `npm run poems:fetch`：下载固定版本文件至本地 `data-source/chinese-poetry` 缓存。
- `npm run poems:import`：校验来源哈希，离线重新转换、筛选和生成诗词库。

导入工具依赖 opencc-js 与 fontkit，仅供开发使用，不会在运行时访问 GitHub。缓存目录由 .gitignore 排除，生成后的诗库和来源清单属于项目源码。更新上游时需主动修改固定提交并重新检查；不会自动改写已经收藏的内容。

## 验证

27 项业务测试通过，其中包含 90 天推荐无近 30 天重复、100 次手动选诗的近期去重、2,008 个唯一 ID、旧数据兼容和展示句来源检查。13 项浏览器流程通过，覆盖全库汉字行书检查、三布局、主题与灵签、天气及收藏持久化。完整人工校对、节气/天气诗词标签推荐仍属于后续工作。
