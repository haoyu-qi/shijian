# 灵签库 · 0.4.1

离线灵签由 6 条扩充至 60 条，数据位于 `src/data/fortunes.json`。原有 1–6 号的签句、签意和寄语保持不变，升级后已保存的每日结果与历史可继续读取，无需迁移。

新增 7–60 号为项目编写的生活签，按从容、行动、相处、求知、自省、调养六类组织，每类九条。每条包含短签句、白话签意及今日寄语；这些新编短句不标作古诗、古籍引文或传统庙签。分类仅为内容维护使用，抽签仍从全部 60 条中随机选择。

每日一次、先保存后展示的规则不变；同日关闭面板、重新打开或重启应用均保留结果。扩库不会替换当天已经抽出的签。待抽签页和设置页显示实际库容量，五套皮肤继续共用同一份签文数据。

质量检查覆盖：连续且唯一的签号、无重复签句、字段完整性、旧六签回归、全部新旧签号恢复、末号抽取与每日结果持久化。浏览器逐条检查 60 条签文在 260 px 窄窗口中的分句排版，字体检查覆盖所有签句汉字。

灵签用于文化娱乐和生活寄语，不作未来事件预测。
