# 诗笺 0.3.0 更新说明

## 五项调整

1. **模板固定**：经典竖版 280 × 700、横向诗钟 520 × 390、月轮竖版 300 × 720，均为逻辑像素。桌面窗口不可手动缩放，移除标题区域拖动事件与拖动权限，并在切换模板时设置相同的最小/最大尺寸。设置、诗词详情等面板仍可滚动阅读。系统工作区不足时保持模板尺寸，优先将窗口顶部放回可见工作区。
2. **辅助文字**：作者、农历、星期、操作提示等统一提高字重和对比度。行书使用原始字重，避免伪加粗使毛笔笔画糊成一团。
3. **顶部控件**：历史、设置、最小化、关闭常驻显示，使用有边框和底色的按钮。无需悬停发现入口。
4. **自定义国内城市**：保留常用城市下拉选择，增加中文或拼音搜索与省市区分信息。过滤境外结果；选中地区后保存其 ID、名称与经纬度，重启可恢复。搜索由用户手动提交，使用 Open-Meteo / GeoNames 数据，需网络，不保证地名库覆盖所有村镇。
5. **灵签**：签文采用卷轴框，按句分行；签号、签意、今日寄语、日期分别展示。未抽取时提示每日一次；已有签文不重抽。窄窗口下六条现有签文均检查无单字落行。

## 验证

- TypeScript/Vite 构建、23 项业务测试通过。
- 11 项常规浏览器流程通过，另有 1 项六条签文长度专项测试通过。
- 真实地名接口成功返回苏州、江苏及合法坐标。
- 原生 Release 窗口启动并读取到 280 × 700 尺寸及新的常驻按钮；拖动/缩放的人工输入回归未完成，系统窗口激活失败，未据此宣称实际拖动测试通过。
- Windows x64 Release 中文安装包重新生成，保留原应用标识与用户数据结构，不清空旧收藏或签文。

安装器仍未代码签名，依赖 WebView2。先前版本保留在 `releases/0.2.2`，此次文件在 `releases/0.3.0`。
